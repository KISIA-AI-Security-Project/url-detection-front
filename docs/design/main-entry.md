# 메인 화면 시안

상태: 2026-10-08 사용자의 실제 서비스 적용 요청으로 운영 `/`에 연결했다.
모드: Operate. 비전문 사용자가 URL을 입력해 빠른 분석을 시작하는 화면이다.

2026-10-06 사용자는 빠른/심층 결과 구성을 확정하고 메인 구성으로 이동했다.
정보 범위 질문에 URL 입력·분석 시작·VirusTotal 선택과 하단의 간결한 최근 분석을 선택했다.

## 이번 시안

2026-10-08 입력 화면 보완: URL/시작을 주행동으로 두고 모델·effort를 나란한 한 설정 영역으로 묶었다.
빠른→심층 안내는 제목 아래 한 번만 표시하고, 정상 모델 안내의 반복 행은 제거했다.
짧은 effort 도움말 다음 VirusTotal을 보조 체크 옵션으로 둔다. 480px 이하에서는 설정이 한 열로 바뀌며
선택값, loading/error/retry/미지원 설명, 키보드 조작과 최소 44px 조작 영역을 유지한다.
색·글꼴·헤더·버튼·최근 분석은 기존 승인 구성을 사용한다. 이 추가 변경의 로컬 검토와 운영 반영은
`evaluation/remediation-20261008/input-design-3/` 증거에서 구분한다.

- 승인된 결과 화면의 아이보리, 차콜, 폰트, 로고, 헤더와 버튼을 재사용한다.
- 가운데 제목과 한 줄 설명 다음에 넓은 URL 입력·시작 버튼을 한 영역으로 배치한다.
- 빠른 분석 후 필요한 경우 심층 분석으로 이어지는 순서를 짧게 설명한다.
- VirusTotal은 기본 해제된 선택이다. 사용자의 최신 요청에 따라 외부 전달 안내 문구를 삭제했다.
- 최근 분석은 아래에 얇은 행으로 배치한다. 사용자의 추가 요청에 따라 기본 3개와 `전체 보기`로 구성하고 접을 때는 `접기`를 표시한다.
- 현재 공개 이력 계약의 URL과 scanId를 사용한다. 위험 라벨, 날짜, 처리 시간, 분석 총계는 추가하지 않는다.
- 로그인 전에는 입력과 VirusTotal이 비활성화되며 중앙에서 로그인으로 이어지는 버튼을 제안한다.
- 로그인 후 기록 있음, 첫 사용, 로그인 전, 준비 중 상태를 검토할 수 있다.

## 경계

실제 `/`와 개발 전용 `/design-preview?screen=home`은 같은 `ServiceEntry` 레이아웃을 사용한다. 사용자가 삭제 요청한
VirusTotal 안내 문구를 제거했고 최근 분석에 같은 3개/전체 보기 컴포넌트를 연결했다.
빠른 분석의 VirusTotal도 접는 버튼 문구를 `접기`로 바꿨다. Cognito, API, SSE는 변경하지 않았다.
`ServiceEntry`는 상태와 동작을 외부에서
받으며, 실제 `/`에서는 기존 인증·분석 요청·최근 분석 재열기 함수와 데이터를 받는다.

검토용 로그인은 화면 상태만 전환한다. URL은 기존 normalizeUrl로 검증하지만 분석 요청은
전송하지 않는다. 가상 최근 기록을 누르면 선택 확인을 검토 영역에 표시하며 실제 결과는
조회하지 않는다. 빠른/심층 결과 미리보기 링크는 기존 예시 화면으로 이동한다.

아래 로컬 확인은 당시 시안 검사다. 운영 적용과 실제 서비스 연결 확인은
[배포 기록](../frontend-deployment-20261008.md)에 별도로 남긴다.

## 로컬 확인

2026-10-06 22:23 KST 빌드와 기존 65개 검사를 통과했다. 예시 URL 입력·유효성 검사,
VirusTotal의 Space 선택, 첫 사용·로그인 전·준비 중 상태를 확인했다. 실제 로그인은 하지 않았다.
최근 분석은 가상 기록 6개로 기본 3개 → `전체 보기`로 6개/`접기` 표시 → 다시 3개를
키보드와 DOM에서 확인했다. 실제 결과를 조회하지 않는 검토 화면이다.

현재 사용자가 보고 있는 985×799 화면의 가로 넘침이 없고 `전체 보기`가 표시됨을 확인했다.
그 화면의 캡처는 상위 폴더의 `main-preview-current.jpg`다. 별도의 숨겨진 QA 탭은 화면 폭이
0인 상태에서 캡처가 불가능했으므로 해당 탭의 overflow 값은 레이아웃 증거로 사용하지 않는다.
최근 분석의 상태 변경 기록은 `main-history-three-qa.json`에 남겼다.
